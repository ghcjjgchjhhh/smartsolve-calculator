# SmartSolve Calculator

A modern, powerful mathematics and physics problem solver built with React, TypeScript, and Tailwind CSS. Features step-by-step solutions, dynamic polynomial calculus, 29 physics formulas, equation solvers, unit conversions, and authentic JAMB/WAEC practice questions.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/your-username/smartsolve-calculator)

## Features
- **Mathematics Solver**: Linear & Quadratic equations (Formula, Factorization, Completing Square), Simultaneous equations, Fractions, Percentages & Ratios, Sequences (AP & GP), Coordinate Geometry, Statistics, Permutations & Combinations, Calculus (Diff & Int), Matrices & Vectors, Pythagoras & Mensuration.
- **Physics Solver**: 29 interactive formulas with solve-for variable selection and step-by-step substitution with SI units.
- **Scientific Calculator**: Full functions (sin, cos, tan, log, ln, roots, powers, factorials, DEG/RAD).
- **JAMB / WAEC Practice**: Authentic exam-style questions with score calculation and exam tips.
- **Unit Converter**: 16 categories with standard SI and Nigerian/JAMB units.
- **Progressive Web App (PWA)**: Fully installable on iOS and Android with offline capability.

## Deploying to Vercel

### Option 1: One-Click Deploy via Vercel Dashboard
1. Go to [vercel.com/new](https://vercel.com/new).
2. Connect your GitHub account and import this repository.
3. Vercel will automatically read `vercel.json` and deploy.

### Option 2: Deploying via Vercel CLI
```bash
npm install -g vercel
vercel
```
For production:
```bash
vercel --prod
```
